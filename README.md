# GoA Community Directory

Website: https://austenjs.github.io/goagetcap5/

The maintained website source is on the [`gh-pages` branch](https://github.com/austenjs/goagetcap5/tree/gh-pages), which is this repository's default branch and GitHub Pages publishing source.

This legacy `master` branch is retained only as a documentation pointer. The obsolete React project, dependencies, duplicate portraits, and unrelated demo pages have been removed. Earlier versions remain recoverable from Git history.

For website changes, edit `index.html` on `gh-pages`; no build step is required.

Private Drive originals and a thumbnail service are prepared. Photo migration and removal from Git history remain pending authorization and verification.
